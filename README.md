# Spend Wise AI 💰

**Take control of your spending with AI-powered financial insights!**

Spend Wise AI is a personal expense analyzer that helps you track your transactions, understand your spending habits, and monitor your monthly budget using Machine Learning.

### ✨ What You Can Do
- **Track Expenses:** Add your transactions and manage your daily spending.
- **Monthly Spending Score:** Analyze your spending performance and get insights into your financial habits.
- **Expense Forecasting:** Predict next month's expenses and identify potential budget overruns.
- **Smart Categorization:** Automatically predict transaction categories using Machine Learning.
- **Spending Habits:** Discover your low-spending, busy, and high-purchase days.

### 🛠️ Built With
Python • Streamlit • Scikit-learn • Pandas • Machine Learning

### 🚀 Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
